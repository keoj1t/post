# Jana Address

Jana Address разбирает строку адреса Казахстана на поля и помогает оператору проверить сомнительные результаты.

## Запуск

Требуется Docker Desktop с Docker Compose. В корне проекта выполните:

```powershell
docker compose up --build
```

Откройте http://127.0.0.1:8080. Остановка: `Ctrl+C`. Для локального запуска  используйте `START.bat --local` (нужны Python и зависимости из `requirements.txt`).

После сборки приложения парсер использует локальные файлы КАТО и SQLite со справочными улицами OSM. Сам разбор адресов не вызывает внешние геокодеры. Интерактивная карта 2GIS, если настроена, требует доступа к сети и отдельного ключа; адрес, отправленный на геокодирование, передаётся 2GIS.

## API

- `GET /health` — состояние сервиса.
- `POST /parse` — разбор одной записи.
- `POST /parse/batch` — пакетный разбор, ответ сохраняет количество и порядок записей.

Пример запроса:

```json
[
  {"id": "rec_00417", "raw_address": "Алматы, Абая 25, кв 12"}
]
```

Ответ содержит `id`, неизменённый `raw_address`, поля адреса, `confidence` и замечания `review`. Неопределённые значения возвращаются как `null`.

## Проверка и производительность

Вручную размеченная разработческая выборка (не обучающий и не скрытый набор) находится в `data/validation_gold.json`.

```powershell
.venv\Scripts\python.exe scripts\evaluate_validation.py
.venv\Scripts\python.exe scripts\benchmark_parser.py --count 1000
```


## Справочные данные

- `reference/kato_ru.csv` — локальная иерархия КАТО.
- `reference/osm_streets.sqlite` — локальные улицы и географические соответствия OSM; покрытие обогащения ограничено городами, присутствующими в этой базе.
- `scripts/build_osm.py` — подготовка SQLite из дампа OSM; исходный PBF не требуется для запуска готового приложения и исключён из Docker-контекста.

Примеры входа и ответа: `data/sample_input.json`, `data/sample_output.json`.

## Карта 2GIS

Карта является дополнительной функцией. Ключ задаётся через `JANA_2GIS_API_KEY`; для Docker его можно положить в локальный `.env`, не добавляя этот файл в Git. Ключ MapGL виден браузеру, поэтому настройте ограничения ключа в кабинете 2GIS. После разбора в блоке карты выберите одну запись, отметьте согласие и нажмите «Показать на карте»: приложение геокодирует только этот адрес и показывает одну точку. Для списка можно переключать выбранную запись. Геокодирование отправляет выбранный адрес 2GIS и требует интернета; ключ должен иметь доступ к MapGL и Geocoder. Без ключа или сети разбор и пакетный API продолжают работать.
