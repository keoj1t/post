# Jana Address

Запуск на этом компьютере: дважды нажмите **START.bat** и откройте **http://127.0.0.1:8080**. Остановка: Ctrl+C в окне запуска. Окружение `.venv` и зависимости уже установлены. Node.js не требуется.

При переносе нужен Python 3. START.bat создаст окружение и установит зависимости; только для первой установки требуется интернет.

## Интерфейс

Белая тема по умолчанию, переключатель тёмной темы, русский и казахский языки. Системный шрифт в стиле Apple: -apple-system / BlinkMacSystemFont / Segoe UI. Внешних шрифтов, CDN и внешних скриптов нет.

Четыре рабочих раздела: адреса, детали и подсветка токенов, очередь проверки, ошибки и исправления. Загрузка TXT/JSON, подсветка, редактирование в таблице и деталях, отмена изменений, очередь по возрастанию уверенности, поиск, сортировка, страницы по 50 строк, экспорт JSON/CSV из таблицы и очереди. Детали показывают замечания по неполным адресам и конфликтам географии. Подтверждённые записи исключаются из числа ожидающих проверки. Введённые адреса и результаты не переводятся при смене языка. Правки адресов хранятся в памяти вкладки; для сохранения используйте экспорт.

## Аккаунты

Регистрация, вход и выход работают через `/auth/register`, `/auth/login`, `/auth/logout`, состояние аккаунта — `/auth/me`. Пароли хранятся как PBKDF2-SHA256 с индивидуальной солью, сессии — на сервере, cookie — HttpOnly / SameSite Strict. Сессия действует 7 дней. При HTTPS cookie получает Secure. Есть ограничение частоты попыток входа и регистрации. Подтверждение почты и восстановление пароля не подключены.

Аккаунты на этом компьютере сохраняются в `data/accounts.sqlite3`; файл исключён из Git. Путь можно переопределить переменной `JANA_AUTH_DB`. При контейнерном запуске для сохранения аккаунтов между пересозданиями контейнера необходимо отдельно настроить постоянное хранилище. Авторизация не изменяет контракт API разбора и не ограничивает гостевую обработку адресов. История адресов к аккаунтам не привязана.

## Редактирование и проверки

Исходники интерфейса: `app/static/page.html`, `styles.css`, `base.js`, `app.js`, `i18n.js`, `quality.js`, `account.js`, `errors-log.json`. Сборка: `.venv\Scripts\python.exe build_frontend.py` или перезапуск START.bat. Итоговый `index.html` содержит все ресурсы внутри и уже включён в проект.

Парсер поддерживает явные жилмассивы (жм, ж/м, жилой массив, тұрғын алап), слитные номера, дм и одну пропущенную букву в известных длинных маркерах. Названия улиц не исправляются по сходству. Добавлен разбор географии внутри строки без запятых, вариантов кварт/подьедз и ориентира с предлогом. Связи в слитных номерах обрабатываются до разделения токенов. Явные противоречащие город и область сохраняются, а уверенность ограничивается 0.55 для ручной проверки. Справочники не менялись. Для аккаунтов добавлен `app/auth.py`, в `app/main.py` подключён только его роутер. Дополнительные зависимости для авторизации не нужны.

Проверки парсера: `.venv\Scripts\python.exe tests.py` и `.venv\Scripts\python.exe -m unittest test_parser_variants -v`.
Браузерные проверки: `.venv\Scripts\python.exe verify_frontend.py`. Скрипт использует установленный Chrome и необязательную dev-зависимость playwright, запускает отдельный сервер на 8081 с временной базой аккаунтов. Пользовательские аккаунты не затрагиваются. Снимки экрана: `.venv/preview-*.png`.

Страница ошибок строится из редактируемого `app/static/errors-log.json`: исходный пример, проблема, исправление и ожидаемые поля. Тест `test_error_page_results_match_the_parser` проверяет каждую запись против настоящего парсера; результаты не являются выдуманной оценкой качества на всём наборе.
